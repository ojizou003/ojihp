# おぢぞうLab. 公式ホームページ

AIを活用した最新テクノロジーで、高品質な成果物を常識はずれの低価格で提供するクリエイティブラボ「おぢぞうLab.」の公式ポートフォリオ・ホームページです。

## 概要 (Overview)

本プロジェクトは、おぢぞうLab.の事業内容（ウェブアプリケーション開発、ブログ記事執筆、テレアポ用営業リスト作成など）を紹介するためのシングルページアプリケーション（SPA風の静的サイト）です。

白黒を基調としたミニマルで洗練されたモダンデザインを採用し、カスタムカーソルやスクロールに連動したアニメーションによって、ユーザーにプレミアムな体験を提供します。

## 主な機能・特徴 (Features)

*   **モダン＆ミニマルデザイン**: 極限まで無駄を削ぎ落としたモノトーン（黒・白・グレー）の配色。
*   **カスタムカーソル**: サイト全体で専用の追従型カーソルを使用し、インタラクティブな操作感を実現。
*   **スクロールアニメーション**: ページをスクロールする際、コンテンツが滑らかにフェードイン(`IntersectionObserver`を利用)。
*   **レスポンシブ対応**: PCおよびスマートフォンで最適に表示される設計。

## 技術スタック (Tech Stack)

*   **HTML5**: セマンティックなマークアップ
*   **CSS3 (Vanilla)**: 変数(カスタムプロパティ)を利用した保守性の高いスタイリング、CSSアニメーション
*   **JavaScript (Vanilla)**: 外部ライブラリ（jQuery等）に依存しない、軽量で高速なDOM操作・イベントハンドリング

## 開発・プレビュー方法 (How to Run)

静的なファイルで構成されているため、特別なビルド環境は必要ありません。

1.  本リポジトリをクローンまたはダウンロードします。
2.  `index.html` をお使いのウェブブラウザ（Chrome, Edge, Safariなど）で開いてください。
3.  （推奨）VSCodeをお使いの場合は、`Live Server`拡張機能を使用すると、ファイルの変更が即座にブラウザに反映されて便利です。

## デプロイ (Deployment)

本サイトは **GitHub Pages** へのデプロイを想定して設計されています。
`main` または `gh-pages` ブランチにプッシュし、リポジトリの設定からGitHub Pagesを有効化するだけで公開可能です。
